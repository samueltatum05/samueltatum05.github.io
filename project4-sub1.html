Server Liquid Cooling System

Summary

This project focused on the micro-level thermal management of high-performance compute hardware. By designing a dedicated liquid cooling loop for a server blade, the system successfully balanced localized heat transfer requirements with stringent limits on allowable pressure drop and pump power, ensuring sensitive components operate safely under peak processing loads.
