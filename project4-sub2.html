Data Center Rack Liquid Cooling System

Summary

Scaling up from individual server constraints, this macro-level project addresses the thermal demands of a fully populated GPU server rack. The focus was on designing supply and return manifolds, optimizing facility-level coolant flow distribution, and minimizing overall energy consumption (PUE) by mapping out system-level thermal resistance networks.
